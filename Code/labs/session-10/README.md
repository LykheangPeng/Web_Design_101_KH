# Lab 10 · Interactive portfolio features

Lab ១០ · មុខងារអន្តរកម្មសម្រាប់ផលប័ត្រ

1. Add a menu button that shows and hides the navigation on small screens by toggling a class. Update aria-expanded on the button.
   បន្ថែមប៊ូតុងម៉ឺនុយដែលបង្ហាញ/លាក់នាវីហ្គេសិនលើអេក្រង់តូច។

2. On the contact page, show a live character counter under the message box using the input event.
   បង្ហាញការរាប់តួអក្សរផ្ទាល់ក្រោមប្រអប់សារ។

3. On submit, prevent the reload and show a thank-you message in a <p role="status"> so screen readers announce it.
   ពេល submit បង្ហាញសារអរគុណ។

4. Add filter buttons on the projects page (All, HTML, CSS, JS) that hide cards that do not match.
   បន្ថែមប៊ូតុងចម្រោះនៅទំព័រគម្រោង។

5. Use every feature with the keyboard only.
   ប្រើមុខងារទាំងអស់ដោយក្តារចុចតែប៉ុណ្ណោះ។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
