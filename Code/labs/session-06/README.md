# Lab 6 · Header, navigation and cards

Lab ៦ · ក្បាលទំព័រ នាវីហ្គេសិន និងកាត

1. Add the box-sizing reset to the top of your stylesheet.
   បន្ថែម box-sizing reset នៅខាងលើឯកសារ CSS។

2. Turn your site header into a flex container with your name on the left and the navigation on the right.
   ធ្វើឱ្យក្បាលទំព័រជា flex container។

3. On projects.html, show three projects as cards in a wrapping flex row, each with a title, a short description and a link.
   បង្ហាញគម្រោងបីជាកាតក្នុងជួរ flex។

4. Use DevTools’ device toolbar to view the page at 360 px wide. Fix anything that overflows.
   មើលទំព័រនៅទទឹង 360px ហើយកែអ្វីដែលហៀរចេញ។

5. Mini project (20%): hand in your three-page site, styled and validated.
   គម្រោងតូច៖ ប្រគល់គេហទំព័របីទំព័រ ដែលបានរចនា និងផ្ទៀងផ្ទាត់។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
