# Lab 2 · Your “About me” page

Lab ២ · ទំព័រ «អំពីខ្ញុំ»

1. In portfolio/, create about.html with a proper head, one <h1> and three <h2> sections: Education, Skills, Hobbies.
   បង្កើត about.html ដែលមាន h1 មួយ និង h2 បី។

2. Add a photo or an illustration you have the right to use, with meaningful alt text and width and height.
   បន្ថែមរូបភាពដែលអ្នកមានសិទ្ធិប្រើ ជាមួយ alt ដែលមានន័យ។

3. Add an unordered list of skills and an ordered list of your top three goals for this course.
   បន្ថែមបញ្ជីជំនាញ និងបញ្ជីគោលដៅបីដែលមានលេខ។

4. Link index.html and about.html to each other, and add one external link with rel="noopener".
   ភ្ជាប់ទំព័រទាំងពីរទៅគ្នា និងបន្ថែមតំណខាងក្រៅមួយ។

5. Run both pages through the W3C validator until there are no errors.
   ពិនិត្យទំព័រទាំងពីរជាមួយ validator រហូតគ្មានកំហុស។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
