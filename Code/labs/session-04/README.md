# Lab 4 · Wireframe and style guide

Lab ៤ · ប្លង់ព្រាង និងមគ្គុទ្ទេសក៍រចនាប័ទ្ម

1. Write a one-paragraph brief: who will visit your portfolio (for example an employer or a scholarship committee) and what you want them to do.
   សរសេរសេចក្តីសង្ខេប៖ នរណានឹងមើលផលប័ត្ររបស់អ្នក ហើយអ្នកចង់ឱ្យពួកគេធ្វើអ្វី។

2. Sketch a wireframe of your home page for a phone and for a laptop, using grey boxes only.
   គូរប្លង់ព្រាងទំព័រដើមសម្រាប់ទូរស័ព្ទ និងកុំព្យូទ័រ។

3. Make a style guide: two fonts, four colours with hex codes, and the contrast ratio of each text and background pair. All body text must reach 4.5:1.
   បង្កើតមគ្គុទ្ទេសក៍រចនាប័ទ្ម៖ ពុម្ពអក្សរពីរ ពណ៌បួន និងអនុបាតពណ៌ផ្ទុយ។

4. Run a five-second test with two classmates: show your wireframe for five seconds and ask what the page is about.
   ធ្វើតេស្តប្រាំវិនាទីជាមួយមិត្តរួមថ្នាក់ពីរនាក់។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
