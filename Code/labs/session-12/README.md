# Lab 12 · Launch your portfolio (final project)

Lab ១២ · ដាក់ផលប័ត្រឱ្យដំណើរការ (គម្រោងចុងក្រោយ)

1. Run the accessibility checklist in 12.1 on every page and fix what you find.
   អនុវត្តបញ្ជីត្រួតពិនិត្យលើទំព័រនីមួយៗ ហើយកែបញ្ហា។

2. Add a unique title and meta description to each page. Run Lighthouse (mobile) and fix the top three issues.
   បន្ថែម title និង meta description ហើយកែបញ្ហាធំៗបីពី Lighthouse។

3. Create a GitHub repository, commit your work in small steps and publish with GitHub Pages.
   បង្កើត repository, commit និងផ្សព្វផ្សាយជាមួយ GitHub Pages។

4. Write a short README.md: what the site is, the technologies, and an honest note on how you used AI.
   សរសេរ README ខ្លីមួយ រួមទាំងកំណត់សម្គាល់ស្មោះត្រង់អំពីការប្រើ AI។

5. Present your site in five minutes: one design decision, one bug you fixed, and one thing you would improve. The rubric is in Appendix A.
   បង្ហាញគេហទំព័ររបស់អ្នកក្នុងរយៈពេលប្រាំនាទី។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
