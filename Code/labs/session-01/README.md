# Lab 1 · Set up your workspace

Lab ១ · រៀបចំឧបករណ៍

1. Install a code editor and two browsers. Create a folder portfolio.
   ដំឡើងកម្មវិធីសរសេរកូដ និង browser ពីរ។ បង្កើតថត portfolio។

2. Type Listing 1.1 into portfolio/index.html. Change the heading to your name and the paragraph to one sentence about you.
   វាយ Listing 1.1 ហើយប្តូរចំណងជើងទៅជាឈ្មោះរបស់អ្នក។

3. Open the page. Press F12, find your heading in Elements and change its text in DevTools. Reload: what happens, and why?
   បើក DevTools ប្តូរអត្ថបទ ហើយ reload។ តើមានអ្វីកើតឡើង? ហេតុអ្វី?

4. Open the Network panel and reload any news website. Find one request with status 200 and, if you can, one with another status.
   ក្នុងផ្ទាំង Network រកសំណើដែលមានស្ថានភាព 200។

5. Ask an AI assistant to explain your page line by line. Write down one thing it explained well and one thing you had to check on MDN.
   សុំ AI ពន្យល់ទំព័ររបស់អ្នក ហើយកត់ត្រាអ្វីដែលអ្នកត្រូវពិនិត្យលើ MDN។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
