# Lab 9 · Console practice

Lab ៩ · អនុវត្តក្នុង Console

1. Create js/practice.js, load it with defer in a test page, and print your name and age with a template literal.
   បង្កើត practice.js ហើយបោះពុម្ពឈ្មោះ និងអាយុ។

2. Write grade(score) that returns A (85+), B (70+), C (50+) or F, and test it with five scores.
   សរសេរអនុគមន៍ grade(score) ហើយសាកល្បងជាមួយពិន្ទុប្រាំ។

3. Make an array of five project objects with title, year and tech. Use filter to list projects from this year and map to make an array of titles.
   បង្កើតអារេគម្រោងប្រាំ ហើយប្រើ filter និង map។

4. Use reduce to count how many projects use CSS.
   ប្រើ reduce ដើម្បីរាប់គម្រោងដែលប្រើ CSS។

5. Break your code on purpose (misspell a variable). Read the error message and explain it to a classmate.
   ធ្វើឱ្យកូដខូចដោយចេតនា ហើយពន្យល់សារកំហុស។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
