# Lab 5 · Typography for your portfolio

Lab ៥ · ពុម្ពអក្សរសម្រាប់ផលប័ត្រ

1. Create css/style.css and link it from every page of your portfolio.
   បង្កើត css/style.css ហើយភ្ជាប់ពីទំព័រទាំងអស់។

2. Apply the fonts and colours from your Session 4 style guide. Use rem for all font sizes.
   អនុវត្តពុម្ពអក្សរ និងពណ៌ពីមគ្គុទ្ទេសក៍រចនាប័ទ្មរបស់អ្នក។

3. Style links, including :hover and :focus states.
   រចនាតំណ រួមទាំងស្ថានភាព :hover និង :focus។

4. Create three utility classes, for example .lead, .muted and .highlight, and use them on at least two pages.
   បង្កើត class ប្រើប្រាស់បី ហើយប្រើវាលើទំព័រយ៉ាងតិចពីរ។

5. Change your browser’s default font size to “Large”. Does your site scale? If not, find the px values to replace.
   ប្តូរទំហំអក្សរលំនាំដើមរបស់ browser។ តើគេហទំព័ររបស់អ្នកពង្រីកតាមទេ?

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
