# Lab 3 · Structure and contact form

Lab ៣ · រចនាសម្ព័ន្ធ និងទម្រង់ទំនាក់ទំនង

1. Rewrite index.html and about.html with <header>, <nav>, <main> and <footer>. Put the same navigation on both pages.
   សរសេរទំព័រឡើងវិញជាមួយ header, nav, main, footer។

2. Add a projects.html page with a table of three course projects: name, date, technology.
   បង្កើត projects.html ដែលមានតារាងគម្រោងបី។

3. Create contact.html with name, email, a topic chosen by radio buttons in a fieldset, and a message. Make sensible fields required.
   បង្កើត contact.html ដែលមានឈ្មោះ អ៊ីមែល ប្រធានបទ (radio) និងសារ។

4. Test the form: submit it empty, then with a wrong email. Then open DevTools, remove required from one input and submit again. What does this prove?
   សាកល្បងទម្រង់ ហើយលុប required ក្នុង DevTools។ តើវាបង្ហាញអ្វី?

5. Navigate the whole site using only the Tab and Enter keys. Note anything you cannot reach.
   ប្រើតែគ្រាប់ចុច Tab និង Enter ដើម្បីរុករកគេហទំព័រទាំងមូល។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
