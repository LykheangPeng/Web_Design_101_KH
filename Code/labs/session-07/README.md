# Lab 7 · A mobile-first portfolio

Lab ៧ · ផលប័ត្រ mobile-first

1. Rebuild your home page layout with Grid and named areas: header, main, aside (for example “Now learning”) and footer.
   បង្កើតប្លង់ទំព័រដើមឡើងវិញដោយ Grid និង named areas។

2. Write it mobile-first: one column by default, two columns from a breakpoint you choose by testing.
   សរសេរ mobile-first៖ មួយជួរឈរជាលំនាំដើម ពីរជួរឈរចាប់ពី breakpoint មួយ។

3. Change the project cards to an auto-fit grid.
   ប្តូរកាតគម្រោងទៅជា grid auto-fit។

4. Make all images responsive, and add loading="lazy" where it makes sense.
   ធ្វើឱ្យរូបភាពទាំងអស់ឆ្លើយតប។

5. Test on a real phone. Record two problems you did not see in DevTools.
   សាកល្បងលើទូរស័ព្ទពិត ហើយកត់ត្រាបញ្ហាពីរ។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
