# Lab 11 · Projects from JSON

Lab ១១ · គម្រោងពី JSON

1. Move your project data into data/projects.json: title, year, tech (an array), description and link.
   ផ្លាស់ទិន្នន័យគម្រោងទៅ data/projects.json។

2. On projects.html, fetch the file and build the cards with createElement. Show “Loading…” first and a friendly error if it fails.
   ទាញយកឯកសារ ហើយបង្កើតកាតដោយ createElement។

3. Rename the file on purpose to test your error message, then fix it.
   ប្តូរឈ្មោះឯកសារដោយចេតនាដើម្បីសាកល្បងសារកំហុស។

4. Add a theme switch (light, dark, system) and remember the choice in localStorage.
   បន្ថែមកុងតាក់ប្តូរទម្រង់ពណ៌ ហើយចងចាំជម្រើសក្នុង localStorage។

5. Optional: show data from a free public API that needs no key, with the source credited on the page.
   ជាជម្រើស៖ បង្ហាញទិន្នន័យពី API សាធារណៈឥតគិតថ្លៃ។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
