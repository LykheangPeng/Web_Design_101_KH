# Lab 8 · Tokens and a dark theme

Lab ៨ · Token និងទម្រង់ងងឹត

1. Move every colour, font, radius and spacing value in your stylesheet into tokens on :root.
   ផ្លាស់ពណ៌ ពុម្ពអក្សរ កាំជ្រុង និងគម្លាតទាំងអស់ទៅជា token។

2. Add a dark theme with prefers-color-scheme. All text must still reach 4.5:1 contrast.
   បន្ថែមទម្រង់ងងឹត ហើយអត្ថបទទាំងអស់ត្រូវតែមានកម្រិតផ្ទុយ 4.5:1។

3. Create a .btn component with hover, focus-visible and disabled states, and use it for every button and call-to-action link.
   បង្កើតសមាសធាតុ .btn ជាមួយស្ថានភាពទាំងបី។

4. Use clamp() for your main heading size.
   ប្រើ clamp() សម្រាប់ទំហំចំណងជើងចម្បង។

5. Turn on “reduce motion” in your operating system and check that your transitions stop.
   បើក «reduce motion» ហើយពិនិត្យថា transition ឈប់។

See the session in the book for explanations. Work in your own `portfolio/` folder (copy `portfolio-starter/` in Session 1).
