1
Foundation

Set the viewport meta tag

Without this single line, mobile browsers render your page at ~980px and shrink it — making everything tiny and unreadable. It tells the browser to match the screen's actual width.

index.html — <head> 
<meta name="viewport"
      content="width=device-width,
               initial-scale=1.0">
→ width=device-width uses the real screen pixels. initial-scale=1 prevents auto-zoom on load.

2
Media queries

Define your breakpoints

Breakpoints are the screen widths where your layout changes. Use min-width (mobile-first) — write styles for small screens first, then add overrides for larger ones.

style.css — media queries 
/* Mobile first — base styles */
.card { width: 100%; }

/* Tablet ≥ 768px */
@media (min-width: 768px) {
  .card { width: 48%; }
}

/* Desktop ≥ 1024px */
@media (min-width: 1024px) {
  .card { width: 32%; }
}
! Always go mobile-first. It forces you to prioritise essential content and is easier to scale up than down.

3
Layout

Use fluid grids — not fixed pixels

Replace fixed pixel widths with CSS Grid and auto-fit. Columns automatically collapse when the screen shrinks — no breakpoints required.

style.css — fluid grid 
.grid {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(240px, 1fr));
  gap: 1.5rem;
}
/* Columns collapse below 240px each */
index.html 
<div class="grid">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
</div>

4
Responsive images

Use <picture> for art direction

The <picture> element lets you serve different image crops or sizes depending on the screen. Wide shots for desktop, tight crops for mobile — all with the same HTML element.

index.html — picture element 
<picture>
  <!-- Desktop: wide landscape -->
  <source
    media="(min-width: 1024px)"
    srcset="hero-wide.jpg">

  <!-- Tablet: medium crop -->
  <source
    media="(min-width: 768px)"
    srcset="hero-medium.jpg">

  <!-- Mobile: portrait/tight -->
  <img
    src="hero-mobile.jpg"
    alt="Hero image">
</picture>
★ Also add srcset with sizes on a plain <img> for resolution switching — let the browser pick the best file size automatically.

5
Typography

Scale type fluidly with clamp()

clamp(min, preferred, max) makes font sizes flow smoothly between screen sizes without any media queries — fewer rules, more elegant results.

style.css — fluid typography 
h1 {
  /* min 28px → scales → max 64px */
  font-size: clamp(1.75rem, 5vw, 4rem);
}

p {
  font-size: clamp(1rem, 1.5vw, 1.125rem);
  max-width: 65ch; /* readable line length */
  line-height: 1.7;
}
→ Keep body text line length under 75 characters on all screens using max-width: 65ch.

6
Images

Make images flexible — always

Images with fixed widths overflow their container on small screens. Two lines of CSS prevent 99% of responsive image problems:

style.css — flexible images 
img {
  max-width: 100%;   /* never overflow */
  height: auto;      /* keep ratio */
  display: block;    /* remove gap */
}

/* For cover images, use object-fit */
.hero-img {
  width: 100%;
  height: 300px;
  object-fit: cover;
}
★ Add this rule to your CSS reset so every image on every page is automatically responsive — no extra work needed.
