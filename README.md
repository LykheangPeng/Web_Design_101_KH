# Web_Design_101_KH
This project is supporting material for Web Design course of PSBU's Bachelor of Computer Science. There consists of the presentation slide, example code, and material. All the material prepared by Lykheang PENG, Industrial Expert Lecturer of PSBU's School of Information Technology.  

## Course Syllabus
- Week 0: Introduction
- Week 1: HTML Fundamentals
- Week 2: CSS Styling
- Week 3: Responsive Design
- Week 4: JavaScript Basic
- Week 5: DOM & Events
- Week 6: Modern JS & APIs
- Week 7: Mid-Term Exam
- Week 8: Introduction to React
- Week 9: State & Props
- Week 10: Effects & Lifecycle
- Week 11: Deployment
- Week 12: Final Project Presentation

## Course Evaluation
- Final Project: 30%
- Final Exam: 30%
- Mid-Term Exam: 20%
- Attendance: 20%
